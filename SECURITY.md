# Security reports

Send private reports to **keith@surething.io**, the project maintainer. Do not include an active
API Key. Include the affected version or commit, reproduction steps, expected behavior and
observed behavior. Use a test Key and redact credentials from logs and screenshots.

If a Key was exposed, revoke it in the [glasser Keys page](https://app.glasser.ai/keys) and create
a replacement. Removing it from OpenSEO alone does not revoke it.

This project is pre-1.0. Security fixes target the current source and next release. No response
time or support period is guaranteed.
