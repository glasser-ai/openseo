# Communication

- Use [ASD-STE100 Simplified Technical English](https://www.asd-ste100.org/about_STE.html) as the writing reference for technical explanations and procedural instructions.
- Use the terminology defined by the current project. Use one term consistently for each domain concept.
- Preserve exact code, commands, paths, identifiers, and quotations.
- **English only** — code, identifiers, comments, docs, UI strings, commits, PRs.
- Comments say **why**, not what.

## Commits

Release: bump `package.json`, merge, push the matching `vVERSION` tag.
